# 40代からの食べ痩せタイプ診断

8問でわかる！あなたが最初に整えたいポイント

スマートフォン向けのセルフチェック診断です（医療的な診断ではありません）。
回答はどこにも送信・保存されません。

## ファイルの中身

| ファイル | 役割 |
| --- | --- |
| `config.js` | **質問文・選択肢・配点・結果の文章・ボタン設定**（編集するのはほぼここだけ） |
| `index.html` | 画面の骨組み |
| `style.css` | 色や文字の大きさなどの見た目 |
| `app.js` | 判定のしくみ・画面の切りかえ（ふだんは編集不要） |

## よくある編集

- **文章を直したい** → `config.js` の `" "` の中の文字を書きかえる
- **配点を変えたい** → `config.js` の各選択肢の `related: { C: 2, A: 1 }` の数字を変える
- **「無料セミナーはこちら」ボタンを出したい** → `config.js` の一番下の `cta` で
  `show: false` を `show: true` に、`url` にリンク先を入れる
- **色を変えたい** → `style.css` の一番上にある色コードを変える

## 判定のしくみ

- **メインタイプ**：Q1・Q2・Q3・Q4・Q6・Q7 の回答で、選んだタイプに1票ずつ。一番票が多いタイプ。
  同点のときは Q1 → Q8 → Q2 → Q3 → Q4 → Q6 → Q7 の順に回答を見て、同点候補に入っているタイプを優先。
- **サブ傾向**：全8問の関連点（`related`）を合計し、メインタイプ以外で一番高いタイプ。
  同点のときは Q1 → Q8 → Q2 → Q3 → Q4 → Q5 → Q6 → Q7 の順で優先。
- 結果ページのバーは関連点の合計を、一番高いものを100%として長さだけで表示しています（数値は出しません）。

## 公開のしかた（GitHub Pages）

1. GitHub でこのリポジトリを開き、**Settings → General** の一番下で公開設定を **Public** にする
   （無料プランでは、非公開のままだと GitHub Pages が使えません）
2. **Settings → Pages** を開く
3. 「Source」を **Deploy from a branch**、Branch を公開したいブランチ・`/ (root)` にして **Save**
4. 数分待つと、ページ上部に `https://ユーザー名.github.io/himaru-diet-quiz/` のURLが表示されます
